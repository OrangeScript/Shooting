# Game_01 基础属性道具

36件新道具：18件正面、12件取舍、6件负面，ID 3001–3036。均为可叠加的普通属性道具，通过现有 ItemDefinition → shooterEffects → ShooterStatEffectDefinition 资产链配置，不按道具编写脚本。

当前场景基础攻击力1、开火间隔0.5秒（2发/秒）、移速5、初始生命10。场景原有击杀成长机制保留：击杀后增加与敌人最大生命等量的永久生命上限；healOnKill 已启用，基础击杀回血比例为100%。因此本表“击杀回血 +5 个百分点”会把100%变成105%，不改变击杀带来的永久上限成长。恢复受当前生命上限限制，小数治疗累计到1点再应用。

同类百分比采用加法叠加：两个“攻击速度+12%”得到1.24倍攻速；实际发射间隔为基础间隔÷倍率，不会使用逐层乘法。攻击力为整数加法。每一层的最大生命变化也会等量调整当前生命，扣减最低保留1点；移除道具撤销对应修正，不修改已获得的击杀成长。重复刷新层数不会重复治疗。

全局有效范围：攻击力最低1；攻速倍率0.25–4；弹速倍率0.3–3；移速倍率0.35–2.5；闪避0–65%；击杀回血总比例0–200%；持续回血0–5点/秒。超出边界的属性按上述范围限制实际生效值。纯负面与部分取舍道具可能在当前下限附近没有额外代价，仍保留账面修正，会抵消后续增益。道具不复活已死亡角色。

权重为相对值，不是百分比。普通速度属性通常权重8，进阶增益6，强攻击属性3–4；取舍道具3–4；负面1。权重保存在道具定义中，供道具发放流程使用；叠层上限由 InventoryCore 统一检查。

## 配置和玩法边界

这些道具仅属于 Game_01 射击玩法（availability = Shooter）。Scene_02 联机竞技场使用另一套属性与拾取流程，不生成仅射击模式生效的道具。旧道具保留原有效果链。基础攻击力提升继续通过原有宠物伤害继承接口生效；其余属性按射击角色自身的属性消费者应用。

## 数据库配置

数据库共47件：36件新基础属性道具、6件原有射击道具、5件竞技场武器。新道具已通过 ItemDatabase 注册，保留属性效果、层数上限、分类和权重配置。

编辑属性数值时修改 CommonStats/Effects 下对应效果资产的 Per Stack；编辑名称、说明、权重和层数上限时修改 CommonStats/Items 下对应道具资产。
